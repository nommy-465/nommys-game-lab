# 迷える子羊を救え！

開発中・試作版

## 掲載用テキスト

**キャッチコピー：** 5匹の迷える子羊を見つけて、みんなで逃げきれ！

狼から逃げながら、ステージに散らばった5匹の子羊を探す救出ゲーム。子羊に近づくと後ろについてきます。全員を連れて、光るゴールを目指しましょう。

十字ボタン・画面ドラッグ・矢印キーで移動。画面上部の矢印がゴールの方向を示します。

立ち止まると狼も一瞬停止。その後はゆっくり近づいてきます。壁を利用して距離を取りましょう。

## 現在の仕様

- 狼は画面外で定期的に発生・消失。同時存在は最大15体。
- 画面内の1体が12秒間隔で1秒間走る（停止中などは開始を待つ）。
- 子羊は5匹。ランダムに配置され、発見前は歩き回る。狼には狙われない。
- タイトル画面をタップして開始。
